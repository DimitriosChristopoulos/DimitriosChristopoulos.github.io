1.1 Convolutions from Scratch

The 4 for loop implementation loops through every pixel in the image, as well as each value in the kernel for the convolution operation. 2 of these for loops are used for each of these operations.

The 2 for loop implementation takes advantage of vectorization, requiring only to loop through the pixels, because we can crop the image to get the patch of pixels we require to perform convolution, and we don't need to loop through the kernel at all. This is a significantly faster implementation than the 4 for loop implementation.

To quantify the difference in performance: The 4 for loop implementation took 2 minutes and 20 seconds to run when using a kernel of size 9, and 10 minutes 8 seconds to finish with a kernel of size 18. The 2 for loop implementation took 18 and 19 seconds respectively. Additionally, the Dx and Dy convolutions went from 9 and 10 seconds to 0.079 seconds and 0.1 seconds.

Part 2: Fun with Frequencies

2.1 Image "Sharpening"

Image sharpening is possible by removing the low frequency information of the image. This gives the appearance that the image is 'sharper', so we can simply blur the image to obtain the low-frequency information, and then subtract that low-frequency information from the original image. Of course, this may work to varying degrees.

Taj Mahal

As seen above in the Taj Mahal, some of the black edges on the building structure are clearer after getting rid of the low-frequency information.

Hagia Sophia

In the Hagia Sophia image above, this is significantly clearer, where we can see that in the middle there is a relatively blurry image, but on the right, there is a much cleaner and sharper image. We can especially see this in the front of the building.

2.2 Hybrid Images

The high pass and low pass filters were chosen according to the research paper attached in the assignment. The logic behind the chosen filters is similar to what we were doing to sharpen the previous images. Since we know that blurring an image gets us the low-frequency information, we can use that not only as a low-pass filter, but also as something that we can subtract from the original image to obtain the high frequency information. The chosen low pass filter was the simple Gaussian which we've been using up until now.

2.3 Gaussian and Laplacian Stacks

In this section we are implementing Gaussian and Laplacian stacks. The difference between a stack and a pyramid is that this time we are not downsampling, we are simply blurring the image one more time as we increment the stack. This is for a similar reason as the coarse-to-fine logic we used for the previous assignment. One thing we need to consider for blurring is that we need a stronger blur filter as we increment the stack, mainly so that we can get the exponential increase that we want from this implementation. Once again, similar to the coarse-to-fine implementation, if we exponentially increase the blur strength, we can get coarser and finer adjustments when we hybridize the image.

2.4 Multiresolution Blending

The mask for the stack is used to combine the 2 images we want as we want. For example, if the mask has values of 1 on one side, and 0 on the other, we are including one image on the left, and the other on the right. In more complicated cases, we can choose where we want pixels from which image, and where we want them. This is what allows us to have more complicated hybridizations.
